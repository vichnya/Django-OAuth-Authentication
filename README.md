# Django OAuth Authentication

Учебное веб-приложение на Django, демонстрирующее регистрацию и авторизацию пользователей с использованием OAuth-аутентификации через Google.

## Цель

На практике изучить работу с системой аутентификации Django и интеграцию стороннего OAuth-провайдера.

## Что реализовано

* авторизация пользователей;
* регистрация пользователей;
* выход из аккаунта;
* защищённая страница пользователя;
* интеграция Google OAuth;
* перенаправление пользователя на страницу авторизации Google;
* обработка запроса доступа к данным пользователя;
* использование Django Allauth;
* работа с формами и системой пользователей Django.

## Основные маршруты

* `/login/` — авторизация пользователя;
* `/register/` — регистрация;
* `/logout/` — выход из аккаунта;
* `/oauth/` — OAuth-аутентификация;
* `/password-change/` — изменение пароля;
* `/password_reset/` — восстановление пароля;
* `/polls/` — раздел с опросами.
